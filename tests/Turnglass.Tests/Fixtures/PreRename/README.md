# Pre-rename compatibility fixture

These compressed SQLite databases were generated by the CodexSessionViewer binaries from commit `f1f4c26` before the Turnglass rename. They contain only synthetic data: one Codex session, custom model prices and UTC settings, one approved insight with review progress, and one retained Visual Studio Copilot usage record.

The old application created all schemas and serialized records. Its web and MCP APIs applied the settings, imported the synthetic logs, submitted the insight, and approved it. The processes were stopped, SQLite WAL files checkpointed, and the databases vacuumed before compression. No real user logs, settings, or account data were included.

Tests decompress these resources into a temporary directory and reopen them with the renamed application through an explicit data-directory setting. Source paths intentionally retain their historical synthetic locations; the compatibility test does not scan them.
